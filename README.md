# MyoReachers

MyoReachers adds reaching environments to [MyoSuite](https://github.com/MyoHub/myosuite). The environments use MuJoCo musculoskeletal models and are intended for reinforcement-learning experiments involving the elbow, and wrist.

## Installation

MyoReachers supports Python 3.8 and newer. Install it from a checkout with:

```bash
python -m pip install .
```

For development, install an editable copy:

```bash
python -m pip install -e .
```

The installation pulls in `myosuite` and its runtime dependencies.

## Environments

Importing `myoreachers` registers these environments with the MyoSuite Gym-compatible registry:

| Environment | Description |
| --- | --- |
| `myoreachersElbow1D6MFixed-v0` | One-degree-of-freedom, six-muscle elbow pose control with a fixed target |
| `myoreachersElbow1D6MRandom-v0` | One-degree-of-freedom, six-muscle elbow pose control with randomized targets |
| `myoreachersWristFixed-v0` | Wrist reaching with a fixed target |
| `myoreachersWristRandom-v0` | Wrist reaching with randomized targets |

The arm, elbow, and wrist environments also register `Sarc` and `Fati` variants for sarcopenia and fatigue conditions. These variants are generated by MyoSuite when the package is imported.

## Quick start

Import the package before calling `gym.make` so the environment registrations are loaded:

```python
import myoreachers
from myosuite.utils import gym

environment = gym.make("myoreachersWristRandom-v0")
observation = environment.reset()

for _ in range(100):
	action = environment.action_space.sample()
	observation, reward, terminated, truncated, info = environment.step(action)
	if terminated or truncated:
		break

environment.close()
```

## Included models

The package includes the MuJoCo XML models and supporting meshes, textures, and materials required by the registered environments. These resources are installed alongside the Python package and resolved internally from the package directory.
